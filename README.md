# Shiori
A personal Android app for tracking anime, manga, novels, and movies.
Shiori 🌸

A personal Android app for tracking anime, manga, novels, and movies.

Shiori is a lightweight, non-commercial Android application designed to help users organize and remember the stories they experience.

Features

- Anime Tracking — Record anime titles, watching progress, ratings, and personal notes.
- Manga Tracking — Organize manga collections and reading progress.
- Novel Tracking — Keep track of novels, reading status, and personal impressions.
- Movie Tracking — Record movies, directors, release years, ratings, and reviews.
- Monthly Gallery — Browse completed works through a visual cover gallery organized by month.
- Local Posters — Support locally stored cover images and poster URLs.
- TMDB Integration — Search for movies and retrieve metadata, including titles, release dates, posters, and director information.

About This Project

Shiori is currently a personal project under active development.

It is intended for private, non-commercial use and is not publicly distributed.

The source code is maintained privately. This repository serves as a public information page for the application.

Data Sources

Movie information is provided through the TMDB API.

This product uses the TMDB API but is not endorsed or certified by TMDB.

Privacy

Shiori is designed around personal media tracking. The application uses a user-provided TMDB API Read Access Token for movie searches.

No API credentials or personal media records are published in this repository.
